# CalculatorRS
A rust-based calculator with a nostd core (see calc.rs)
> [!NOTE]
> This is just a project to learn about parsers for now there's no intent to support anything.
> No AI was used (check individual commits) to write this project (and limited access to documents)

## Features
It can handle basic operators (`+, -, *, /, ^`) and parentheses in standard notation.
Both interactive CLI mode and command with argument mode.

## Usage
`rust-calculator` for interactive mode\
`rust-calculator <expr>` for command-line mode
> [!WARNING]
> For now, you need to remove all whitespaces from the input
